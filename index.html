Privacy Policy

EXTENCION FOR SSW · 25 November 2026

This page describes the Chrome extension EXTENCION FOR SSW. The extension runs on the person's own computer. It does not send extension data to a server operated by the developer.

Data stored on this computer

  • The PIN is not saved. It is used only to derive an encryption key with PBKDF2-HMAC-SHA-256. The key encrypts a local vault with AES-256-GCM.
  • The vault may contain the branch code, the company domain, the username, and the CPF. These values stay in Chrome storage on this computer.
  • The SSW password is kept in memory only while the person signs in. It is not written to storage.
  • A count of wrong PIN attempts is kept for the current browser session so the extension can lock after repeated failures.

Data sent to SSW

When the person uses the extension, it talks only to https://tms.ssw.inf.br. Sign-in is sent to /bin/ssw0422. Later requests use the Chrome session already open on that site to consult or issue a complementary CT-e that the person asked for. The password and the CT-e data go to SSW, not to the developer.

What this extension does not do

  • It does not sell data and it does not use data for advertising.
  • It does not transfer user data for purposes unrelated to the extension's single purpose.
  • It does not use or transfer user data to determine creditworthiness or for lending.
  • It does not include analytics or third-party trackers.

How to delete the data

Remove the extension in chrome://extensions, or clear the extension's site data. That deletes the encrypted vault from this computer.

Contact

Questions about this policy can be sent through the Chrome Web Store listing for EXTENCION FOR SSW.

Política de privacidade

A extensão EXTENCION FOR SSW roda no computador da pessoa. O PIN não fica gravado: ele só deriva a chave que cifra, neste Chrome, a filial, o domínio, o usuário e o CPF. A senha do SSW não é armazenada. Ela segue apenas para https://tms.ssw.inf.br quando a pessoa entra. A extensão não envia esses dados ao desenvolvedor, não vende dados e não mede crédito. Para apagar o cofre, remova a extensão.
